# Smart-Traffic-Violation-Detection-Monitoring-System
Smart Traffic Violation Detection &amp; Monitoring System is an AI-based solution that uses YOLO, OCR, and IoT to detect vehicles, identify traffic violations like red-light crossing and overspeeding, extract number plates, and store records in a MySQL database with a web dashboard for monitoring and analysis.
# Smart Traffic Violation Detection & Monitoring System

## Project Overview
The Smart Traffic Violation Detection & Monitoring System is an AI and IoT based traffic monitoring solution designed to automatically detect traffic violations such as red-light crossing and overspeeding. The system uses computer vision techniques to detect and track vehicles from live camera feeds, identify violations, extract vehicle number plates using OCR, and store violation data in a database for monitoring and analysis.

This project is being developed as an ISD Lab and IoT Lab project with a focus on teamwork, Scrum workflow, GitHub collaboration, and intelligent traffic monitoring.

---

## Features
- Real-time vehicle detection using YOLO
- Vehicle tracking with unique IDs
- Red-light violation detection
- Speed estimation using virtual lines
- Number plate extraction and OCR recognition
- Violation evidence image capture
- MySQL database integration
- Web-based dashboard for monitoring
- Search, filter, and analytics functionality
- Role-based management system

---

## System Workflow

Camera → Frame Capture → Vehicle Detection → Vehicle Tracking → Violation Detection → OCR → Database → Dashboard
